## What's new in 1.6.3 (compared to 1.6.2)

**In short:** redesigned Web Companion with desktop/mobile layout, theme-styled custom dropdowns, and remote library management; critical torrent and install stability fixes eliminating Switch panics and download stalls; independent manifest-verified catalog channel with offline descriptions; NAND installation safety margins; RuTracker tracker enrichment for magnet downloads; port archive guidance and explicit SD card save status.

### Stability & Torrent Engine (Critical Fixes)

- **Buffer exhaustion & CPU fault prevention (`4a59aba`):** graceful recovery on Switch BSD socket `ENOBUFS` errors under heavy peer churn without connection storms; transient piece buffer allocation drops are no longer treated as received blocks and do not abort the process; native libnx exception handler logs fault addresses (`[fault] desc=... pc=... lr=... far=...`) to `pipensx.log`.
- **Install rate degradation fix (`e653bf2`):** fixed rate-EMA ratchet collapse behind the install gate where streaming downloads could exponentially decay to 0 B/s.
- **Peer strike cooldown (`3480b47`):** suppressed cascading strikes during active peer cooldown to prevent prematurely dropping viable peers (#95).
- **Torrent start & shutdown reliability (`6f1caba`):** fixed application hang and crash when closing pipensx with active torrents in the queue.
- **RuTracker tracker enrichment (`b7c36fb`):** enriched HTTPS-cached magnet torrents with RuTracker trackers for faster discovery (#94).
- **Checkpointing & reboot recovery (`d4dcf84`):** active streaming installs checkpoint at 4 MiB (was 32 MiB) with liveness markers, safely resuming after unexpected console reboots without leaving dangling NCM placeholders.
- **Repeated import merge (`65c337a`):** re-adding an existing release merges newly selected files into the active download task instead of rejecting it.
- **UI freeze (ANR) detection (`9a5189c`):** main loop stall tracking logs the exact contention point when intensive I/O or NSZ decompressor threads delay Borealis frame rendering.

### Web Companion Redesign & Remote Management

- **Sidebar navigation & layout:** modern, responsive desktop and mobile interface with quick navigation across Downloads, Catalog, Installed library, Add, Diagnostic Logs, and Settings.
- **Page-styled custom dropdowns:** replaced raw browser-native `<select>` popups with custom dropdown components matching the pipensx theme (dark and light modes, smooth chevron rotation, accent highlights, and checkmarks).
- **Live source & storage status:** companion sidebar and activity panel reflect the active download method (Direct BitTorrent vs Debrid provider with credential status), live microSD free space, queue counters, and mini-queue activity.
- **Remote game library (Installed tab):** remotely inspect games installed on the Switch, check for available updates, and queue update tasks without touching the console.
- **Diagnostic logs & live telemetry:** view a real-time tail of `pipensx.log` filtered by category (Real-Debrid, Install, Errors, Performance) and run installation speed benchmarks directly from the browser.
- **Over-the-air NRO updates:** upload a newly built `pipensx.nro` through the web companion and apply it on the Switch with an authorization PIN modal.
- **Comprehensive localization:** Web Companion fully translated across 8 languages (English, Russian, Brazilian Portuguese, French, Spanish, Simplified Chinese, Italian, Korean).

### Installation & Storage Safety

- **NAND system memory safety margin (`9355c40`):** installations to internal storage (BuiltInUser / NAND) enforce a 512 MB safety buffer (`kNandSafetyMarginBytes`) to prevent Horizon OS storage panics and system crashes on tight EmuNAND partitions.
- **FAT32 resume overwrite resolution (`9b9f5d2`):** eliminated overwrite conflicts and fsync failures during debrid split downloads on FAT32 filesystems.
- **Base game title classification (`0e96a79`):** game titles embedding words like "patch" (*Dispatch*) or "mod" (*Modern Combat*) are no longer falsely flagged as updates/mods and skipped when higher version patches exist.
- **Port & archive guidance modal (`041063a`):** informative guidance dialog for non-PFS0 ports and archives (zip/7z/rar), explaining that files are stored in `/switch/pipensx/downloads/` and need extraction to SD root or manual installation via DBI.
- **Explicit download-only status (`50c91a1`):** non-package and download-only tasks clearly report *«Files saved to SD card»* upon completion rather than ambiguous installation status.
- **Separated history clear from deleting files (`8a46c61`):** completed entries can be cleared from Downloads history without touching downloaded files, while deleting files is a separate action.

### Catalog, Debrid & Localization

- **Dedicated pipensx-catalog channel (`4aa8cad`):** manifest-verified catalog release channel (`manifest.json` + `catalog.json`) with hash validation and delta downloads.
- **Offline descriptions (.pdx):** bundled offline descriptions across 8 languages for fast browsing without requiring internet access.
- **AllDebrid provider (`c36d03e`):** added AllDebrid alongside TorBox, TorrServer, and Real-Debrid.
- **Grouped Real-Debrid downloads:** multi-file releases via Real-Debrid are handled as grouped archive transfers with CRC and size validation.
- **Korean (`ko`) locale (`e53d78f`):** full Switch UI localization in Korean.
- **Italian (`it`) settings fix (`7e6635b`):** correct mapping of Italian system preferences to `LOCALE_IT`.
- **Dimmed non-.torrent files (`21cb83d`):** file picker dims unsupported extensions instead of hiding them completely.
- **Touch-selectable settings (`2bed201`):** settings sections can be navigated by direct touch.
